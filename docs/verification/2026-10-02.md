# Verification record — 2026-10-02

## Product

PromiseLock: local, opt-in review before a browser message claims an attachment, link, or completed placeholder.

## Evidence and decision

Four candidates were considered:

1. **PromiseLock — 24/25**: catches a high-frequency mistake at the visible send boundary; local deterministic MVP is possible today; the warning is easy to demonstrate and share.
2. **ContextBorrow — 20/25**: useful, but overlaps the existing Tab2Patch context workflow.
3. **ErrorZip — 19/25**: useful, but overlaps the existing Failcase and Reprocard workflows.
4. **OutsideClick — 19/25**: narrower browser-routing pain with weaker repeat use.

Research anchors: [Codex local DLP request](https://github.com/openai/codex/issues/25585), [GitHub secure-use guidance](https://docs.github.com/en/actions/reference/security/secure-use), and existing local paste tools [PromptCloak](https://github.com/ezequiel0822-netizen/promptcloak) and [PasteVeil](https://github.com/luoowei/pasteveil). These support the problem space, not product-market fit.
